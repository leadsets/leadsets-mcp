# Security policy

## Reporting a vulnerability

Please report security issues with the Leadsets MCP server or API privately to **security@leadsets.ai**. Don't open a public issue.

Include what you found and how to reproduce it. We'll acknowledge your report within 3 business days and keep you updated until it's resolved.

## API keys

Never put an API key in a public repository, an issue, a shared chat or browser code. If a key leaks, revoke it in the dashboard and create a new one. Revoking a key also disconnects every MCP client that signed in with it.
